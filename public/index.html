常见问题

Token 是什么？安全吗？

Token 是登录 ChatGPT 后的访问凭证，用于把会员开通到你的账号。Token 仅用于本次充值，加密存储，充值完成后立即删除。

充值后多久可以到账？

提交 Token 后通常 1 分钟内完成，订单页会实时显示进度，完成后刷新 ChatGPT 即可生效。

充值失败怎么办？

若因 Token 失效导致失败，可在订单页重新提交；其他原因请凭订单号联系客服处理或退款。

在哪里查看我的订单？

点击右上角「我的订单」即可查看在本浏览器下过的订单。订单记录只保存在当前浏览器，更换设备时请使用下单后保存的订单链接。
